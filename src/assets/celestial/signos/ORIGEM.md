# Origem das ilustrações dos signos

Geradas individualmente em 2026-11-07 pela ferramenta integrada `image_gen`, conforme autorização do usuário, para a tarefa 153. Sem CLI ou chave de API externa. Cada arquivo é uma geração independente, sem atlas e sem recorte coletivo. Originais preservados na pasta de imagens geradas do Codex; cópias PNG com transparência estão nesta pasta e fazem parte da publicação do projeto.

A correspondência visual foi conferida individualmente. Capricórnio usa a cabra marinha tradicional; Áries usa o carneiro. A seleção no app vem do signo sideral calculado, por `src/components/dashboard/signos.ts`. As ilustrações não representam posições planetárias calculadas nem acontecimentos previstos.
