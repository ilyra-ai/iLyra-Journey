## Conferência visual

O Markdown foi renderizado com `react-markdown` e GFM instalados no projeto,
com uma folha de estilo de leitura local. Não se trata de inspeção da interface
nativa do GitHub. A prévia foi aberta no Chrome for Testing em 1280, 390 e 320 px:
logo oficial carregado, emojis visíveis, texto legível e sem estouro horizontal.
Três verificações axe não encontraram violações nas regras WCAG executadas
(dez regras aprovadas por largura). As capturas foram inspecionadas localmente.

## Recuperação do ambiente

A manutenção automática removeu a cópia anterior antes da publicação desta tarefa.
O snapshot foi recuperado do commit `903db9b357af0e186b77b9ce990f401b87fabe38`,
com os 858 arquivos e a árvore original
`16086287d736a965ab6ce59b69f5617ff76fc0d6` conferidos. A base de cidades foi
recuperada pelo link autorizado de download, pois a leitura comum retornou vazia
para o arquivo maior que um megabyte. Não se regenerou ou substituiu a base.

A cópia paralela revelou arquivos inconsistentes; os afetados foram restaurados
sequencialmente e só então a árvore completa foi aceita. O índice preserva os
modos originais; `core.filemode=false` evita diferenças de permissão impostas
pelo transporte deste ambiente. O clone por CLI não tinha autenticação disponível;
a recuperação e as publicações usam a conexão autenticada do GitHub. O Git local
tem o snapshot original como limite raso, sem branches ou worktrees adicionais.

A instalação congelada foi aprovada. O Corepack disponibilizou o pnpm 11.28.4
fixado no manifesto. Na cópia limpa, `next-env.d.ts` ainda não havia sido gerado;
`next typegen`, conforme a documentação instalada, preparou as declarações antes
da conferência de tipos. Nenhum import ou verificador foi removido para aceitar
a ausência desse arquivo gerado. MySQL 9.7.2 real foi preparado isoladamente,
sem substituir o banco por outro mecanismo.

O executor de QA inicialmente repassava `NODE_ENV=production` também aos
unitários; isso acionou corretamente a proteção que recusa origem de cobrança
derivada da requisição em produção. O executor foi corrigido para usar o modo
de testes nas suítes. A proteção e os testes do app foram preservados.
